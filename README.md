# Pep Software Official Website

Production web application for **Pep Software** — Web Development, Mobile Apps, Custom Software, SaaS Products, ERP & CRM Software, UI/UX Design, and Digital Marketing.

- **Official URL:** [https://pepsoftwares.com](https://pepsoftwares.com)

---

## Getting Started

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## Production Build

To build the application for production:

```bash
npm run build
```

To run the production server locally:

```bash
npm run start
```
